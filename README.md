# Plant Disease Classification

## Project Overview
This project uses Deep Learning and Vision Transformer (ViT) to classify plant leaf diseases from uploaded images.

## Dataset
PlantVillage Dataset containing 54,304 images across 38 classes.

## Pretrained Model
Google ViT Base Patch16 224

## Fine-Tuned Model
https://huggingface.co/sohaila-12345/plant-disease-vit

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- Streamlit
- Vision Transformer (ViT)

## How to Run
Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
